# Data Model
- `Symbol`: Exchange, Ticker, Asset Class.
- `Candle` (OHLCV): Timestamp, Open, High, Low, Close, Volume. (Stored in TimescaleDB).
- `TradeIdea`: Generated by Strategy Engine, includes entry, stop-loss, target, confidence, and reasoning.
- `Order`: Status (Pending, Filled, Rejected), quantity, price, timestamp.
- `Position`: Current holdings, unrealized PnL.
- `JournalEntry`: Audit log of user approvals/rejections and agent decisions.
